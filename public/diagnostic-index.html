Getting Started with Diagnostics

  • Step 1: Click "Open Diagnostic Tool" to run the full diagnostic
  • Step 2: Click "Run Full Diagnostic" button to analyze your system
  • Step 3: Review each tab (Environment, Components, Loading States, Network)
  • Step 4: If you see stuck loaders, check the Console tab for details
  • Step 5: Open your application in another tab and interact with components
  • Step 6: Use "Start Live Inspection" to monitor changes in real-time

What to Look For

  • ✅ Alpine.js: Should show "Loaded"
  • ✅ Livewire: Should show "Loaded"
  • ✅ Stuck Loaders: Should show "0" (none detected)
  • ✅ Components: Should show the number of interactive elements
  • ✅ Network: All assets should show as loaded
